# Legal / copyright hygiene

Service Scout is an **internal research assistant**. It writes short evaluations (URLs, paraphrased facts, free-tier numbers) to Notion.

## Do

- Store links and short notes.
- Respect Tavily, Notion, and host API terms and rate limits.
- Re-check a vendor’s ToS/robots when you later **integrate** a data source into a product.

## Don’t

- Paste full articles, READMEs, or docs into Notion.
- Resell or redistribute search result corpora.
- Put vendor trademarks in *this* product’s name (mentioning them in research notes is normal).
- Commit API keys.

This is practical hygiene, not legal advice.
